The intelligence stack

Four progressive research phases — each layer building on the last.

04 — Policies & Thresholds

Decisions that protect users

Model outputs are gated through a policy layer before any action is triggered — ensuring safety, fairness, and reliability.

🎯
Leak Detection Threshold
PPM exceeding a calibrated upper control limit (μ + 3σ) triggers an immediate alert. Threshold is personalised per household baseline to reduce false positives.
📊
Per-user Average Baseline
A rolling 30-day weighted mean establishes each user's definite average consumption. Deviations >15% flag anomalous usage for review.
🚨
Outlier Detection
IQR-based and isolation-forest methods flag sensor faults, cylinder tampering, or atypical refill events without poisoning the training data.
🔔
Low-Gas Alert Policy
Time-to-empty (Tₑ) prediction below 48 hours triggers a proactive refill recommendation, factoring in vendor lead times and user history.
🛡️
Fail-safe Override
If sensor data is missing for >5 minutes, the system defaults to the last valid reading and notifies the user — never silently drops safety monitoring.
🔄
RL Re-order Policy
Agents are constrained by a minimum gas buffer policy — no re-order recommendation can deplete the reserve below a 20% cylinder floor.
